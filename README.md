# 人工智能导论 - 练习系统

北航士嘉书院 人工智能导论课程配套练习系统。

## 功能

- 单选题 + 多选题 混合练习
- 答题倒计时（可暂停）
- 自动跳转下一题
- 正确/错误实时反馈 + 详细解析
- 错题本 + 重做机制
- 连击统计 & XP 等级系统
- 顺序/随机 两种模式
- 题库筛选（全部/单选/多选）
- 深色主题，纯离线运行

## 使用

直接打开 `index.html` 即可，无需任何依赖。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 上线版（代码混淆，体积 330KB） |
| `AI导论练习系统_v3_dev.html` | 开发版（可读源码，196KB） |

## 技术栈

- 纯 HTML/CSS/JS，零依赖
- 所有数据本地存储（localStorage）
- 字符串混淆 + 变量名混淆
